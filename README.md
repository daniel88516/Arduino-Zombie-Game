# Arduino Zombie Game

以 Arduino 與 ILI9341 TFT 螢幕製作的動態小遊戲。專案使用 Adafruit GFX 與 ILI9341 函式庫繪製遊戲畫面與角色圖像，主要程式位於 `zombie_loli.ino`。

## 使用方式

1. 在 Arduino IDE 安裝 `Adafruit GFX` 與 `Adafruit ILI9341` 函式庫。
2. 依程式中的腳位定義接上 ILI9341 TFT 螢幕。
3. 將 `zombie_loli.ino` 上傳至 Arduino 開發板。

此專案用於練習 Arduino 圖形顯示與互動式遊戲設計。
